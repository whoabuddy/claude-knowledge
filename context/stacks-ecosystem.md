## When to Load This File

Reference this file when:
- Linking to ecosystem resources
- Verifying correct GitHub repos or npm packages
- Looking up DeFi protocol URLs
- Finding official documentation

**Key distinctions:**
- `@aibtc/mcp-server` = AIBTC's MCP server (aibtcdev org)
- `x402-stacks` npm = x402 protocol SDK (x402Stacks org)
- stacks.org = Foundation | stacks.co = Ecosystem directory
